# Анализ банковских транзакций

Проект для анализа банковских транзакций из Excel-файлов с формированием отчетов, расчетом кешбэка и интеграцией с внешними API.

## Цель проекта

Создать систему автоматизированного анализа банковских операций для:
- Обработки транзакций из Excel-отчетов
- Анализа расходов по категориям за различные периоды
- Расчетов повышенного кешбэка по категориям
- Формирования сводных отчетов с курсами валют и стоимостью акций

## Основные функции

- **Импорт данных**: Автоматическое чтение Excel-файлов из папки `data/`
- **Анализ кешбэка**: Расчет наиболее выгодных категорий за указанный месяц
- **Отчеты по расходам**: Анализ трат по категориям за последние 3 месяца
- **Внешняя интеграция**: Получение актуальных курсов валют и биржевых котировок
- **Автоматическое логирование**: Сохранение результатов каждого запуска в папку `log_result/`

## Технологии

- Python 3.8+
- Pandas - обработка табличных данных
- Requests - работа с внешними API
- Poetry - управление зависимостями
- Pytest - тестирование

## Установка и настройка

### 1. Клонирование репозитория
```bash
git clone https://github.com/Neekkys/Analysis_Of_Banking_Transactions.git
cd analysis_of_banking_transactions
```

### 2. Установка зависимостей
```bash
poetry install
```

### 3. Настройка окружения
Скопируйте и настройте конфигурационные файлы:

```bash
# Копируем шаблон .env файла
cp .env.example .env

# Редактируем .env, добавив API ключи:
# API_KEY_CURRENCIES=ваш_ключ_от_currency_api
```

Поместите Excel-файлы с банковскими отчетами в папку `data/`. Файл должен содержать лист "Отчет по операциям" со следующими колонками:
- Дата операции
- Категория
- Сумма операции
- Кэшбэк
- Номер карты
- Описание

## Использование

### Быстрый старт
```bash
# Запуск основного скрипта
python -m src.main
```

### Параметры запуска
Основные параметры можно изменить в файле `main.py`:
- `main_response("2025-04-20 16:20:00")` - дата для анализа. Анализ начинается с начала месяца и заканчивается
на введенной дате
- `get_increased_cashback(df, 2025, 4)` - год и месяц для анализа кешбэка
- `spending_by_category(df, "Супермаркеты", "2025-04-30 16:20:00")` - категория и дата для анализа расходов. 
Расходы анализируются за последние 3 месяца


### Результаты работы
По умолчанию результаты каждого запуска сохраняются в папку `log_result/` в формате:
- `main 01.01.2025 12-30-45.txt` - полный результат работы
- Включает JSON-ответы и табличные данные

## Описание модулей

### `main.py`
Главный модуль, запускающий весь процесс анализа:
- Получает данные из Excel
- Формирует JSON-ответ с информацией о картах и транзакциях
- Анализирует кешбэк за указанный месяц
- Создает отчет по расходам за последние 3 месяца
- Сохраняет результаты в файл через декоратор `@save_result_in_file()`

`Если в декоратор указать параметр, то файл с результатами будет называться:
<параметр> <дата и время работы функции>`

### `views.py`
Формирует JSON-ответ для отображения данных:
- Приветствие по времени суток
- Информация по картам (последние цифры, расходы, кешбэк)
- Топ-5 транзакций по сумме
- Курсы валют из `user_settings.json`
- Стоимость акций из внешнего API

### `services.py`
Сервисы обработки данных:
- `get_full_df()` - загрузка и сортировка данных из Excel
- `get_increased_cashback()` - анализ категорий с повышенным кешбэком

### `reports.py`
Формирование отчетов:
- `spending_by_category()` - анализ трат по категории за 3 месяца
- `@save_result_in_file()` - декоратор для сохранения результатов

### `utils.py`
Вспомогательные функции для всех модулей:
- Работа с файлами и путями
- Форматирование дат и периодов
- Запросы к внешним API (валюты, акции)
- Обработка и фильтрация данных

## Настройка API

### 1. Валютное API (apilayer.com)
Добавьте в `.env`:
```
API_KEY_CURRENCIES=ваш_ключ
API_URL_CURRENCIES=https://api.apilayer.com/exchangerates_data/latest
```

### 2. API акций (finage.co.uk)
Добавьте в `.env`:
```
API_KEY_STOCKS=ваш_ключ
```

### 3. Настройка отслеживаемых инструментов
В `user_settings.json` укажите:
```json
{
    "user_currencies": ["USD", "EUR"],
    "user_stocks": ["AAPL", "GOOGL", "TSLA"]
}
```

## Распространенные вопросы

### Q: Где разместить Excel-файлы?
A: В папке `data/` в корне проекта. Программа автоматически найдет первый файл с расширением .xlsx/.xls

### Q: Как изменить анализируемую категорию?
A: В файле `main.py` измените параметр в вызове `spending_by_category()`

### Q: Где найти результаты работы?
A: В папке `log_result/`, файлы создаются автоматически с временной меткой
